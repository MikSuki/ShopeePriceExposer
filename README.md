## Description
A Chrome extension designed to uncover hidden price ranges on Shopee.

## Quick Start

### 1. Direct Load
1. Open `chrome://extensions/` in Chrome.
2. Enable **Developer mode** (top right).
3. Click **Load unpacked** (top left) and select the `/ShopeePriceExposer/extension` folder.

### 2. Build from Source
Run the following commands to install dependencies and build the project:

```bash
npm install
npm run build
